# Assembled model / Modelo montado

One file per driver size with every part of one side (right) in its assembled position, skin plane z = 0,
ear-canal axis at the origin. Left side = mirror in x. The occipital link wire is not modelled in the CAD.

* `UMEH-2_assembly_<D>mm_R.3mf` — one named, coloured object per part (opens in slicers/viewers).
* `UMEH-2_assembly_<D>mm_R.stl` — the same parts in one mesh (no boolean union; for viewing, not printing).
* `*_externo.png`, `*_lado_da_cabeca.png` — renders from outside and from the head side.

Um arquivo por tamanho de driver com todas as peças de um lado (direito) na posição montada, plano da pele z = 0.
O lado esquerdo é o espelho em x. O fio da ligação occipital não está modelado no CAD. Para imprimir use as peças
separadas em `stl/common/` e `stl/module_<D>mm/`.

Generated by `calc/assembly_export.py` (OpenSCAD `placed_<part>`, paths set for this machine) and `calc/assembly_merge.py`.
