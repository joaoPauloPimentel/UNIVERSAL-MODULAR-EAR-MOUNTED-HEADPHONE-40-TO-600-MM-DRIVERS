# UMEH-3: roteiro dos testes reais

Os cálculos usam valores típicos [A] para a almofada, os drivers, os atritos e a pele. Estes testes confirmam o que
importa. Anote os resultados e mande para atualizar o relatório.

## 1. Pesagem (balança de cozinha, 0,1 g se possível)

| Peça | Calculado (g) | Medido (g) |
|---|---|---|
| Concha impressa (oval) | 22,4 | |
| Anel de baioneta (com raios) | 2,4 | |
| Assento (3 discos de EVA + placa de quebrar + tiras) | 4,0 / 2,9 / 1,6 (40 / 50 / 60 mm) | |
| Almofada oval (uma) | 10 | |
| Driver (um) | 15 / 26 / 40 (40 / 50 / 60 mm) | |
| Gancho completo (fio, tubos, sela, palheta, bucha) | ~12 | |
| Faixa completa (1,8 mm reta) | ~12 | |
| Um lado montado com metade da faixa | ~74 / 84 / 97 | |

## 2. Bucha do gancho (escolher o furo)

Imprima as três buchas de teste (furo 1,35 / 1,45 / 1,55 mm). Passe cada uma no fio de 1,6 mm:

- Escolha a que **desliza com firmeza** (você move com os dedos, mas ela não escorrega sozinha com o peso do fone).
- Se a de 1,35 ainda deslizar fácil, sua impressora faz furos grandes; se a de 1,55 nem entrar, faz furos pequenos.

## 3. Queda

Com uma concha montada (com driver e almofada, sem gancho para não entortar), solte de **1 m** sobre piso de cerâmica,
10 vezes: 3 de frente (almofada), 3 de costas (tampa), 4 de quina. Depois de cada queda veja:

- O driver continua preso e o anel não girou?
- Há trinca na tampa, na borda arredondada ou na caixa do conector?

Se a quina trincar, a solução é parede de 1,6 mm (+~2 g por lado). Avise antes de imprimir de novo.

## 4. Esteira

1. Ajuste o fone (passo 8 da montagem) e caminhe 5 minutos, depois corra 20 minutos no ritmo de sempre.
2. Anote: o fone se mexeu? Em que momento (pisada, virar a cabeça, puxão do cabo)?
3. Depois de 20 minutos, veja a raiz da orelha (onde a sela apoia): marca vermelha que some em poucos minutos é
   normal; dor ou marca que dura mais de 30 minutos não.
4. Opcional, se conseguir filme sensível à pressão (Fujifilm Prescale LLW): coloque um pedaço sob a sela por 1 minuto
   em pé. A meta é menos de 4 kPa parado.

## 5. Som e vedação

- Parado: toque uma música com grave forte e aperte levemente a concha contra a cabeça. Se o grave quase não muda, a
  almofada está vedando.
- Correndo: o grave "respirar" um pouco no ritmo da passada é esperado (calculado).
- Se os médios ficarem ásperos ou com eco, ponha mais fibra no copo, um pouco de cada vez.
